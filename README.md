# ILUMA Local (Android)

Açık kaynak Android BLE uygulaması. IQOS ILUMA i / i PRIME cihazlarını hesap veya ülke seçimi olmadan yerel Bluetooth bağlantısıyla kontrol etmeyi hedefleyen **deneysel** projedir.

Cihaz bağlantısı gerçek donanımda test edilmemiştir. Önce yalnızca okuma işlevlerini deneyin. Philip Morris International ile ilişkili değildir.

## APK

GitHub Actions → **Build Android APK** → son başarılı çalışma → **Artifacts** → `IlumaLocal-debug-apk`.

Kod, GPL-3.0 lisanslı [hauntedfail/iqos](https://github.com/hauntedfail/iqos) BLE/SCP protokol tanımlarından yararlanır. Lisans: GPL-3.0.
